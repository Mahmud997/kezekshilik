# School Attendance Pro v4

Система учета школьной посещаемости на Firebase.

## Что добавлено
- Firebase Authentication + роли `admin` / `duty`.
- Главная панель со статистикой за сегодня.
- График записей по классам и график статусов.
- Отметка опозданий и отсутствий.
- Журнал с фильтрами по периоду, классу и статусу.
- Раздел «Ученики»: поиск, фильтр по классу и профиль ученика.
- История посещаемости конкретного ученика.
- Импорт учеников из Excel без дублей и с пакетами по 450 записей.
- Отчеты и экспорт в Excel.
- Удаление ошибочной записи только администратором.
- Локальные даты без ошибки UTC.
- Экранирование пользовательских данных перед выводом в HTML.
- `firestore.indexes.json` для основных запросов.
- Адаптивный интерфейс для телефона.

## Firebase
1. Создайте Firebase Project.
2. В Authentication включите Email/Password.
3. Создайте пользователей.
4. Создайте Firestore Database.
5. Скопируйте `config.example.js` в `config.js` и заполните конфигурацию.
6. Примените `firestore.rules`.
7. Примените индексы из `firestore.indexes.json` (если используете Firebase CLI).
8. Для каждого пользователя создайте `users/{UID}` с `{ "role": "admin" }` или `{ "role": "duty" }`.

## Права
- `admin`: ученики, импорт, отчеты, экспорт, удаление.
- `duty`: отметка посещаемости и просмотр журнала/профилей.

## GitHub Pages
Загрузите файлы в репозиторий и включите GitHub Pages. Добавьте домен GitHub Pages в Firebase Authentication → Authorized domains.

`config.js` не добавляется в Git: он указан в `.gitignore`.
